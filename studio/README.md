# Studio Folder

This folder contains Python files generated from your Archestra topology.

## How it works:

1. Design your architecture in the Orchestra Designer
2. Connect nodes (MCP servers → Agents → Clients)
3. Save the topology
4. Python files are auto-generated here based on your design

## Files are generated when:
- You save the topology in Orchestra Designer
- Archestra AI is connected and running
- You have nodes with connections

## To start fresh:
Delete all .py files in this folder. They will be regenerated when you save your topology.

## Note:
These files are dynamically generated from Archestra AI.
Do not manually edit unless you know what you're doing.
